# ClayMath

The honest math of pottery: shrinkage and throw sizing, pieces per bag of clay, cone temperatures against kiln limits, firing costs, and cost per piece.

Static site. No build, no backend, no tracking. Open `index.html`.

- **Engine:** `engine.js` - pure functions, tested in Node.
- **App:** `app.html` - four cards (shrinkage, bag yield, firing, cost) with body presets.

Part of the App Factory: https://github.com/iLanis-agent/app-factory
